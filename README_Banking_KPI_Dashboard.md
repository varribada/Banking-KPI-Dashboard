# Banking KPI Dashboard | Excel Portfolio Project

An Excel-based analysis of a **synthetic dataset of 5,000 customers** from a fictional bank. The project explores the customer portfolio, loan and mortgage exposure, and indicators of payment delays across customer ratings and branches.

> **Portfolio / learning project:** All customer and bank data are fictional and were generated with ChatGPT.

## Project objective

Build an end-to-end Excel dashboard that turns a customer-level dataset into a concise overview of portfolio size, credit exposure, payment delays, and customer segmentation. This is my first complete Excel portfolio project, created to apply the skills learned during my initial Excel training.

## Dataset and workbook

The dataset contains 5,000 synthetic customer records, including customer ID, age, annual income, account type, loan amount, mortgage amount, branch, customer rating, and loan payment status.

The workbook has three sheets:

- **Dati_Clienti:** source customer data.
- **Analisi_Pivot:** PivotTables and supporting analysis.
- **Dashboard:** headline KPIs, five charts, and a summary of key insights.

## Excel skills demonstrated

- Excel tables, filtering, sorting, and number formatting
- Formulas for conditional counting and aggregation, and lookup functions
- PivotTables for customer, loan, and branch analysis
- KPI calculations and percentage-based comparisons
- Five charts and a consolidated dashboard

I used ChatGPT as a learning and project-development assistant. I worked through the Excel exercises and built the workbook with guidance, using the project to understand and practice the techniques listed above.

## Limitations

This project uses synthetic data and is intended to demonstrate Excel and analytical skills, not to estimate real-world bank performance.
